`hydroloom.errors` holds the exception and warning classes hydroloom raises. `HydroloomError`, a `ValueError`, is raised for a problem in the input table that the caller can fix; a vocabulary or column-name problem is a `KeyError` and mixed-type identifiers a `TypeError`. Its subclass `RepresentationError` is raised when a table lacks the representation or columns a function needs. Warnings other than deprecations are `HydroloomWarning`, and each one points at the line in the caller's code that made the call.
