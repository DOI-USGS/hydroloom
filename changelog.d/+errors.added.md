`hydroloom.errors` holds the exception and warning classes hydroloom raises. `HydroloomError`, a `ValueError`, is raised for a problem in the input table that the caller can fix. Its subclasses `RepresentationError` and `CRSError` are raised when a table lacks the layout or columns a function needs and when a coordinate reference system is geographic or missing. Warnings other than deprecations are `HydroloomWarning`, and each one points at the line in the caller's code that made the call.
