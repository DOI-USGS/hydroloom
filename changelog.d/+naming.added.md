`align_names` renames the columns hydroloom knows by another name to its standard names and changes nothing else: identifiers keep their type and a missing `toid` stays missing. `hy_reverse` renames standard names back to those of one source, given as `source="nhdplus"`, `"nhdplushr"`, `"3dhp"`, or `"hydrofabric"`, in lowercase, so `id` becomes `comid`. With `source=None`, the default, it returns the table with its names unchanged, because Python cannot yet register the names a table came in with. `is_hy` reports whether a table is in the form `as_hy` returns: standard names, an `id` column with no missing values, and identifier columns as text. `name_definitions` returns a table of every standard name and its definition.
