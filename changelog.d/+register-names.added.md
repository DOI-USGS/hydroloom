`register_names` is public. It registers input column names as aliases of standard names for the rest of the session, so `align_names`, `as_hy`, and `hy_reverse` recognize them: `register_names({"FlowlineID": "id"})` makes a `FlowlineID` column `id`. Aliases are stored in lowercase. `replace=True` drops earlier registrations and keeps the aliases hydroloom ships. Used as `with register_names(mapping):`, the registration is undone when the block exits. A value that is not a standard name, or an alias that is a standard name other than its value, raises `KeyError` and registers nothing.
