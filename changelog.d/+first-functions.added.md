`as_hy` renames the columns hydroloom knows by another name to its standard names (`COMID` becomes `id`, `ToCOMID` becomes `toid`), turns identifiers into text, and gives a missing `toid` the empty string that marks an outlet (a flowline that flows to nothing else in the table). `representation` reports which representation a table follows (the pattern of its columns), such as an id/toid list or a fromnode/tonode list; it reads the column names and the `id` values only. `make_index_ids` returns an `IndexIds` that gives each flowline's downstream or upstream flowlines as integer positions, for walking the network, and `mode="both"` returns the two as a pair. All three raise `RepresentationError` when no column becomes `id` and `HydroloomError` when an `id` value is missing.
