`as_hy` renames the columns hydroloom knows by another name to its standard names, as `COMID` becomes `id` and `ToCOMID` becomes `toid`, turns identifiers into text, and gives outlets (flowlines that flow to nothing else in the table) an empty `toid`. `representation` reports which network layout a table follows, such as an id/toid list or a fromnode/tonode list; it reads the column names and the `id` values only. `make_index_ids` returns an `IndexIds` that gives each flowline's downstream or upstream flowlines as integer positions, for walking the network, and `mode="both"` returns the two as a pair. All three raise `RepresentationError` when no column becomes `id` and `HydroloomError` when an `id` value is missing.
