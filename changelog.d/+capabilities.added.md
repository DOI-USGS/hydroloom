`capabilities` reports which hydroloom functions a table can be passed to as it stands. It returns one row per registered function, ordered by function name, with `available` true where the table has the representation and columns the function needs, and `via` naming the one conversion, `add_toids` or `make_node_topology`, that would make an unavailable function callable (`""` when there is none). It never raises: a table with no `id` column, or anything that is not a table, has no representation, so only functions that take any table can be available. It is importable from `hydroloom._hy` and is not yet in `hydroloom.__all__`, since no conformance case runs it in Python.
