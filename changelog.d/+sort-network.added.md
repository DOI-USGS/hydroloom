`sort_network` returns the rows of a network ordered upstream to downstream, so every flowline comes after every flowline that drains to it. Outlets, and flowlines that drain to the same flowline, are taken in byte order of their identifiers as text, so `"10"` comes before `"9"` and any row order of the input gives the same output. `split=True` adds `terminal_id`, the `id` of the outlet each flowline drains to, and `outlets` limits the result to the networks above the flowlines named. `add_topo_sort` sorts the same way and adds `topo_sort`, numbered from the number of flowlines down to 1 at the last outlet; it replaces an input `topo_sort` column, such as NHDPlus `Hydroseq`, under the input's name. Both raise `HydroloomError` when the network holds a cycle or an outlet is not an `id`, and `sort_network` raises it when `split=True` and one named outlet lies upstream of another. A node table with `fromnode`, `tonode`, and `divergence` is converted with `add_toids` first; a table with neither `toid` nor node columns raises `RepresentationError`.
