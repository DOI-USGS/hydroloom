`is_dendritic` returns `False` when a network has a divergence and `True` otherwise. It reads two things the table records: a `divergence` value of 2, which marks the minor path leaving a divergence in NHDPlus coding, and, unless `validate_data=False`, an `id` that repeats beside a `toid` column, which is how a flowline with two downstream connections is listed. Column names are aligned to hydroloom names first, so an NHDPlus table with `COMID`, `ToCOMID`, and `Divergence` gives the same answer as one already renamed with `as_hy`. A table `as_hy` cannot read raises what `as_hy` raises, including `HydroloomError` on an (`id`, `toid`) pair listed twice. A node table whose divergences show only as a shared `fromnode`, with no `divergence` column, returns `True`.
